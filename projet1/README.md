# AAP Centrale Lille - Découverte de l'environnement

Ce projet contient un environnement de développement Python configuré via VS Code Dev Containers.

## Structure

- `.devcontainer/Dockerfile` : image de base pour le projet
- `.devcontainer/devcontainer.json` : configuration VS Code pour ouvrir le projet dans le conteneur

## Outils installés

- Python 3.14
- git
- curl
- tree
- less
- nano
- manpages
- pytest
- pycodestyle
- numpy
- matplotlib
- ruff
- pdoc
- rich

## Utilisation

1. Ouvrir le dossier du projet dans VS Code.
2. Installer l'extension `Dev Containers`.
3. Choisir `Dev Containers: Reopen in Container`.
4. Commencer le développement dans l'environnement configuré.

## Utilisateur par défaut

Le conteneur utilise l'utilisateur `aap`.
